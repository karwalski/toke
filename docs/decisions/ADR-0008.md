**Date:** 2026-07-02
**Status:** accepted — **implemented** (conform 180/0), shipped in v0.4
**Deciders:** Matt Watt
**Story:** 116 Workstream A / A3

## Context

v0.3 used a single `=` for **equality**, with binding, assignment, and
declarations *also* using `=`, disambiguated positionally. This overload was the
root of the grammar's worst non-determinism: `lp(go=1)` is ambiguous between a
loop-init assignment and a while-guard equality `go == 1`, forcing the parser into
an **unbounded forward scan** to classify the loop header. It also inverts the
universal base-model prior, where `==` is equality and `=` is assignment —
directly increasing the rate of invalid/mis-generated programs from LLMs, which is
the exact failure toke exists to reduce.

## Decision

Split the operators:

- `=` — binding / mutable binding / assignment / declarations (`m= i= t= f=`) /
  loop init & step. **Statement position only.**
- `==` — equality; `!=` — inequality. **Expression position.**
- A bare `=` in expression/comparison position is a hard parse error **E2002**
  (`` `=` is assignment; use `==` for equality ``), emitted at the exact byte
  offset of the `=`.

```
EqExpr = CompareExpr [ ( '==' | '!=' ) CompareExpr ] ;
```

Implementation (from the approved A3 plan): lexer gains `TK_EQEQ` (mirroring the
existing `<=` two-char case); `parse_compare` accepts `==`/`!=` and rejects bare
`=`; equality remains one `NODE_BINARY_EXPR` op so codegen/fmt are unaffected.

## Consequences

- **Breaking.** v0.3 sources with equality `=` do not compile under v0.4. This is
  the primary reason v0.4 is a major bump. Migration is mechanical: the E2002
  offset stream is a precise, false-positive-free rewrite list (assignment/bind/
  loop `=` are statement position and never flagged) — see `scripts/migrate_eq*.py`.
- Enables ADR-0009: the loop-init unbounded scan is deleted; `lp(` becomes
  fixed-lookahead.
- Token cost of `==` is +1 only on the un-retrained tokenizer; a v0.4 BPE retrain
  (Workstream D) merges `==` to ~1 token like `<=`/`!=`. Net ≈ 0.
- Spec: [toke-spec-v0.4 §B](/docs/spec/toke-spec-v0.4/); `known-limitations.md` #6.
