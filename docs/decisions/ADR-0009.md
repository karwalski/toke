**Date:** 2026-07-02
**Status:** accepted — **implemented** (conform 180/0), shipped in v0.4
**Deciders:** Matt Watt
**Story:** 116 Workstream A / A2, A4, A5

## Context

The v0.3 spec claimed a strict **LL(1)** grammar decidable with **exactly one**
token of lookahead, and promised a normative FIRST/FOLLOW "Appendix X". Neither was
true: an Appendix X was never written, and the real grammar needed more than one
token in a few places (loop-init classification, `.get` postfix). Publishing an
inaccurate formal property is worse than useless for the project's goal — the whole
value proposition to LLM tooling (constrained decoding, verifiable generation)
rests on the grammar's stated determinism being *real and checkable*.

Separately, the audit required short-circuit logical operators (A2) to retire the
"flag-soup" idiom, and a cleanup of the `.get(...)` postfix backtracking (A4).

## Decision

1. **State the honest property (A5).** The grammar is **backtrack-free**: the
   parser never rescans consumed input. It is **not** pure LL(1); a small,
   **enumerated** set of productions require **bounded lookahead ≤ 3 tokens**.
   These exceptions (E1–E5) and the FIRST-sets are normative in **Appendix A of
   `grammar.ebnf`**; `toke.gbnf` is the machine-readable form for constrained
   decoding. An implementation that backtracks or needs unbounded lookahead is
   non-conforming.
2. **Remove the worst offenders (A4).** With the `=`/`==` split (ADR-0008), delete
   the loop-init unbounded forward scan — `lp(` is now fixed-lookahead. Restructure
   `.get(...)` postfix parsing to branch on `arg_count` with no `pos` reset.
3. **Add `&&` / `||` (A2).** Left-associative, short-circuit, `bool` operands;
   `||` looser than `&&`, both looser than equality/comparison.

## Consequences

- The published grammar property is now verifiable (`scripts/grammar_check.py`
  checks GBNF well-formedness + corpus accept-set). Constrained decoding (F) and
  the from-scratch training grammar (G) can rely on it.
- Retires v0.3 §3/§10 "one token of lookahead" text and the "Appendix X" promise.
  Docs asserting "exactly one token of lookahead" (`design.md`, `why.md`,
  `guide/01-why-toke.md`) are corrected to "backtrack-free, bounded lookahead".
- `&&`/`||` + expression-`if` (ADR-0007) together eliminate mut-flag and flag-soup
  idioms; enforced by the idiom judge.
- Spec: [toke-spec-v0.4 §D, §E](/docs/spec/toke-spec-v0.4/).
