# WHAT THE GATE ASKS.  Every stdlib entry a toke program can call that reaches
# an fs / net / env-write / process-spawn primitive must pass a
# TK_REQUIRE(TK_CAP_<class>) of that class on the way (ADR-0010; the broker is
# deny-by-default since 124.4g).  This file is what it already knows about.
#
# THIS FILE IS SELF-FAILING.  A finding not listed here fails the gate; a
# line that no longer matches any finding is STALE and fails the gate too.
# When you gate an entry, delete its lines in the same commit.
#
# Two kinds of line, `|`-separated, every field required:
#
#   exempt  | file.c:function | primitive | date | story | reason
#       A sink that is not the PROGRAM's authority: it applies to every entry
#       that reaches it.  Keep these few and specific.
#
#   ungated | entry | file.c:function | primitive | date | story | reason
#       A known gap -- the entry really does reach the primitive with no gate.
#       Every one of these is a defect to fix, not a decision.

# ── exempt: not the program's authority ────────────────────────────────────

# Entropy.  A fixed path, read-only, and the only way to get random bytes on
# a platform without arc4random/getentropy.  Granting fs.read to call
# crypto.randombytes would be a capability that means nothing.
# 121.20 (CRY-01) moved crypto.c's and encrypt.c's fallbacks into the shared
# tk_secure.h:tk_random_bytes, which aborts instead of returning unfilled.
exempt | tk_secure.h:tk_random_bytes | fopen | 2026-09-29 | 121.20 | /dev/urandom fallback (no arc4random/getrandom); fixed path, entropy only, aborts on failure
exempt | auth.c:auth_apikeygenerate | fopen | 2026-09-29 | 121.22 | /dev/urandom fallback (non-BSD); fixed path, entropy only

# The server's own worker processes.  http.serveworkers et al. bind under the
# net gate (http.c bind_listen) and then fork copies of THIS program to accept
# on that socket; nothing else is executed.  Not process.spawn.
exempt | http.c:http_serve_workers | fork | 2026-09-29 | 121.22 | pre-fork workers of the same image after a net-gated bind; no exec
exempt | http.c:http_serve_tls_workers | fork | 2026-09-29 | 121.22 | pre-fork TLS workers of the same image after a net-gated bind; no exec

# Spawn's own PATH resolution.  process.spawn is gated process.spawn; the
# access(X_OK) probes over the startup PATH snapshot (AMB-03, 124.4h) are how
# it finds the program it has been granted to run.
exempt | process.c:exec_no_ambient_path | access | 2026-09-29 | 121.22 | X_OK probe of the PATH snapshot inside a process.spawn-gated spawn

# A log file's life after it was opened.  log.openaccess / log.openerror take

# directory.  That is the authority the open acquired (124.4c: gate once, at
# acquisition), reached from every http.serve* entry through log_request.

exempt | log.c:alog_sync_inode | stat | 2026-09-29 | 121.22 | inode check of a log opened under fs.write
exempt | log.c:apply_retention | opendir | 2026-09-29 | 121.22 | rotation of a log opened under fs.write
exempt | log.c:apply_retention | stat | 2026-09-29 | 121.22 | rotation of a log opened under fs.write
exempt | log.c:apply_retention | unlink | 2026-09-29 | 121.22 | rotation of a log opened under fs.write

exempt | log.c:compress_to_gz | unlink | 2026-09-29 | 121.22 | rotation of a log opened under fs.write

# TZ.  time.parse / time.withtz / time.utcoffset used to set TZ, call
# tzset/mktime and restore it -- six exempt lines here until 121.42 (6)
# (2026-09-30) made them read the zone rules themselves.  What they read now
# is the system time-zone database, which libc's tzset read before with no
# grant either: a relative zone name, no "..", under $TZDIR or
# /usr/share/zoneinfo (tz_safe_name).  Not a program-chosen path.
exempt | tk_time.c:tz_file_offset | fopen | 2026-09-30 | 121.42 | the system time-zone database ($TZDIR or /usr/share/zoneinfo), relative name, no ".."; replaces the six TZ setenv/unsetenv exemptions
