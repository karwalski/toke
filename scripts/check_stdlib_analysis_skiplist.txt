# 135.3b was already taken by the math.h shadowing row: triage=135.3c, empty TU=135.3d,
# tls/openssl=135.3e, metrics latency=135.3f, dead statics=135.3g, nonhost limits=135.3h.
# check_stdlib_analysis_skiplist.txt — the backlog `make lint` and
# `make lint-nonhost` are carrying, read by scripts/check_stdlib_analysis.py.
#
# Filed 2026-09-23 by story 135.3a.
#
# WHY THERE IS A BACKLOG AT ALL.  Until 135.3a neither gate could fail:
# `make lint` ran clang's --analyze in one command, and --analyze does not
# honour -Werror, so the target printed 97 warnings and exited 0.  It also
# only ever saw $(SRCS) -- the LINK set -- so 104 of the 132 files in
# src/stdlib/ were analysed by nothing and compiled under -Werror by nothing.
# Widening the set to $(ANALYZE_SRCS) and making the gate fail exposed 150
# analyzer warnings across 59 (file, checker) pairs, six modules that do not
# survive -Wall -Wextra -Wpedantic -Werror on the HOST, and eight that do not
# survive it with the host platform macro undefined.  None of that is new
# breakage; all of it is what the old gate was not looking at.
#
# THIS FILE IS SELF-FAILING.  It follows the pattern of
# scripts/check_tki_skiplist.txt: an entry stops being a skip the moment it
# starts passing.
#
#   * a `compile` or `nonhost` entry whose file now builds clean is STALE and
#     FAILS the gate -- delete the line in the same commit as the fix;
#   * an `analyze` entry whose count has DROPPED is STALE and FAILS the gate
#     -- lower the number, or delete the line when it reaches zero;
#   * an entry naming a file that is no longer in $(ANALYZE_SRCS) is STALE;
#   * anything failing that is NOT listed here fails the gate outright.
#
# So the number can only go down, and it cannot go down silently.  Do not add
# a line to make a red gate green without a story next to it.
#
# RECORD KINDS
#
#   compile <path>                      # host -Wall -Wextra -Wpedantic -Werror
#   nonhost <path>                      # the same, with -U__APPLE__ / -U__linux__
#   analyze <path>::<checker> <count>   # clang --analyze, by checker
#
# The analyze key is (file, checker) with a count rather than a line number
# on purpose: line numbers move under every unrelated edit and would make this
# file rot for no reason.  The cost is that fixing one warning and adding
# another under the same checker in the same file is invisible; the count is a
# ratchet, not a fingerprint.

# ════════════════════════════════════════════════════════════════════════════
# nonhost — the #else branch of every platform conditional, built
#
# Undefining the host macro reaches first-party #else branches on the host
# SDK.  It is not a cross-compile: the system headers are still the host's,
# so a branch that needs a foreign header cannot be built this way.  Those
# two cases are marked TECHNIQUE below and are not defects.
# ════════════════════════════════════════════════════════════════════════════
