## Patterns — measured canonical forms (catalogue fa57606a3a04; 19 entries, 19 provisional)
- cond: Use statement-if returning from each branch, not mut-flag then if/el assigns [cond-bind-if]
- cond: Use `el if` chain as one expression, not mut-flag ladder of independent ifs [cond-elif-chain]
- cond: Use `||` inside one expression-if, not flag soup: two ifs setting one mut [cond-bool-combine]
- cond: Use `el if` chain expression, not mut copy then two clamping ifs [cond-clamp]
- cond: Use expression-if selecting the literal, not mut string flag overwritten by an if (127.15 fixed → interpolate the bool `"\(c)"`) [cond-bool-render]
- acc: Use lp accumulating into a mut, not `xs.reduce(0;&addf)` [acc-sum]
- acc: Use lp with if and counter, not `xs.reduce(0;&step)` with expr-if step [acc-count-if]
- acc: Use `xs.sort(&cmp).get(0)`, not `xs.reduce(xs.get(0);&mn)` (hot path: lp tracking the running minimum) [acc-min-max]
- acc: Use `x=x.append(v)`, not `x=x+@(v)` [acc-array]
- acc: Use parallel arrays + linear key search + `c=c.set(j;…)`, not seeded map, `m=m.set(k;m.get(k)+v)` [acc-map-build]
- acc: Use sort a copy, append when != previous, not seen-map keyed by `"\(v)"` (127.11 fixed → `if(!out.contains(v)){out=out.append(v)}`) [acc-dedupe]
- str: Use `s.builder` / `s.add` / `s.build`, not `r=s.concat(r;part)` chain [str-build-loop]
- str: Use interpolation `"\(a)-\(b)-\(c)"`, not nested `s.concat` chain [str-interp-vs-join]
- str: Use interpolation `"\(n)"`, not `s.fromint(n)` [str-num-format]
- str: Use lp prepending with `s.concat`, not `s.concat(s.repeat(" ";p);d)` [str-repeat-pad]
- str: Use `.append`-built, direct `s.add(b;labels.get(i))` reads, not `+@()`-built, interpolated read (127.10 fixed → `.append`-built, interpolated read `"[\(labels.get(i))]"`) [str-array-render]
- err: Use `let v=chk(x)!$myerr`, not `mt … {$ok:v v;$err:e <$myerr{…}}` re-raise [err-propagate]
- err: Use `<mt chk(x){$ok:v v;$err:e -1}`, not `let r=mt …; <r` [err-default]
- err: Use sequential guard returns `if(..){<-1};`, not nested if/el with returns [err-validate-early]
