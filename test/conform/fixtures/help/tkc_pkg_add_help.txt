Usage: tkc pkg add <name> <constraint> [--git <url>]

Add a dependency or change its constraint, then write pkg.lock.

Flags:
  --git <url>         The package's git source (https://, ssh:// or user@host:path)
  --allow-file-source Accept file:/// package sources (local override)
  --diag-text         Emit diagnostics as human-readable text
  --diag-json         Emit diagnostics as JSON (the default)
  --help              Print this help and exit
