# WHY THIS FILE EXISTS
#
# diff-codegen is the root of trust for the corpus programme (story 131.27's
# re-freeze is premised on it). Until 2026-09-23 it only diffed behaviour
# signatures, so a program that crashed or failed to compile was "green" as
# long as it kept doing so. Thirteen of its 118 records were exactly that:
# test/standalone/test_str.tk was recorded [true,"signal",null] — a clean build
# that segfaults with zero bytes of stdout — and twelve more were recorded
# [false,null,null]. The gate printed "118 checked, 0 behaviour change(s)".
#
# So an unhealthy outcome (compile failure, compile timeout, run timeout,
# signal kill) now FAILS the gate unless it is named here with a reason.
#
# THIS LIST IS SELF-FAILING. An entry whose program has become healthy is
# STALE and fails diff-codegen: remove the line and re-record the baseline.
# Same contract as scripts/check_tki_skiplist.txt. You cannot quietly fix a
# quarantined defect and leave the line rotting here, and you cannot quietly
# add a fresh crash — `--record` refuses to write an unquarantined unhealthy
# signature at all.
#
# A quarantine entry is a filed defect, not a permanent exemption. Every line
# below needs a story that removes it.
#
